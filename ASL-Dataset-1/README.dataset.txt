This project provides a specialized computer vision resource for the detection and translation of American Sign Language (ASL) signs. By utilizing this multi-class dataset, which features 18 common ASL words such as "thank-you," "help," and "sorry," developers can build assistive communication tools designed to bridge the gap between sign language users and non-signers.

## Ways to Use ASL Dataset Dataset

1. **Real-Time Sign Language Translation:** Integrate the model into mobile applications or video conferencing software to provide instant text or speech captions for users communicating through common ASL phrases.
2. **Assistive Educational Tools:** Build interactive learning platforms that provide real-time feedback to students practicing sign language, ensuring their hand positioning and movements correctly match the target word.
3. **Contactless Public Service Kiosks:** Enhance accessibility at airports, hospitals, or government buildings by allowing deaf or hard-of-hearing individuals to interact with automated kiosks using standardized sign language gestures.
4. **Sign Language Data Augmentation:** Use the annotated bounding boxes as a foundation for training more complex neural networks, combining this dataset with letter-based sign datasets to create comprehensive translation systems.
5. **Smart Home Gesture Control:** Adapt the model to recognize specific ASL signs as command triggers for smart home devices, providing an intuitive, non-verbal interface for controlling lighting, security, or appliances.

# Overview

The ASL Dataset is an object detection dataset of a few common ASL words w/ bounding boxes. It was curated as a resource for a student capstone project at Neumont College of Computer Science. This resource is **free for public use**.

Thank you to SignASL.org for providing many of the photos found in this dataset

# Use Case

This dataset was used to train an object detection model in combination with the **American Sign Language Letters** dataset for realtime sign language translation.
